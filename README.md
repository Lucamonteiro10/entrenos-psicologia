## 🚀 Como Visualizar o Site

1. **Abrir diretamente:**  
   Basta dar dois cliques no arquivo `index.html` no seu explorador de arquivos para abrir em qualquer navegador (Chrome, Edge, Safari, Firefox).
   
2. **Via Servidor Local (opcional):**  
   Se preferir testar em um servidor web local, abra o terminal nesta pasta e execute:
   ```bash
   python -m http.server 8000
   ```
   E acesse no navegador: `http://localhost:8000`
